# Core Beauty Hub — Website

A professional, single-page marketing website for **Core Beauty Hub** (@corebeautyhub), the aesthetic-injectables practice by **Nur, Certified Injector**, serving the DMV area (DC · Maryland · Virginia).

Built with the **ui-ux-pro-max** design intelligence skill.

## Quick start

Just open the file in a browser:

```bash
open index.html
```

No build step, no dependencies — it's a single self-contained HTML file (fonts load from Google Fonts; images load from Unsplash with graceful fallbacks).
